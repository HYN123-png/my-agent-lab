# 陪签装企产品完整设计

## 一、产品定位

### 1.1 产品名称
**"装修合同陪签服务"**

Slogan：**"确认落地，明确细节，安心签约"**

### 1.2 核心定位

#### 陪签 ≠ 找茬，陪签 = 落地执行
```
陪签不是：
✗ 现场重新审合同
✗ 现场砍价
✗ 重新找问题

陪签是：
✓ 确认之前的问题改了没
✓ 明确模糊细节（材料型号、开工时间）
✓ 推进签约（帮业主和装企达成一致）

类比：
- 审合同 = 体检（找问题）
- 陪谈单 = 治疗方案讨论（怎么改、砍价）
- 陪签单 = 手术确认（确认没问题、签字开刀）
```

### 1.3 服务分层（基于是否买过审合同）

#### 场景A：买过"验房+审合同套餐"
```
业主状态：
- 已经有验房报告、实测图、合同审核报告
- 已经拿着审核报告跟装企谈过了
- 装企改了部分问题
- 准备签约

陪签人拥有的数据：
✓ 验房报告（房屋质量问题）
✓ 户型实测图（精确尺寸）
✓ 合同审核报告（之前审出的问题）
✓ 面积对比表（实测 vs 产权证）

陪签重点：
✓ 对照审核报告，确认问题改了没
✓ 对照实测数据，确认面积、工程量对不对
✓ 明确模糊细节
✓ 推进签约

定价：
- 线上陪签：1000积分
- 线下陪签：1500积分
```

#### 场景B：没买过审合同
```
业主状态：
- 没有验房报告、没有实测数据
- 没有之前的审核报告
- 只有装企提供的合同、报价单、图纸

陪签人只能看：
- 装企的合同文本
- 装企的报价单
- 装企的设计图纸

陪签重点：
✓ 现场审合同（相当于现场做一次审合同）
✓ 凭经验判断（没有实测数据对照）
✓ 明确细节
✓ 推进签约

服务局限：
✗ 无法核对面积（没有实测图）
✗ 无法核对工程量（没有验房报告）
✗ 深度不够

定价：
- 线上陪签：2500积分
- 线下陪签：3000积分

说明：
价格贵，鼓励业主买前置服务
相当于"审合同+陪签"打包
```

## 二、服务内容与流程

### 2.1 线上陪签

#### 服务参数
```
服务时长：1-1.5小时
服务方式：远程（微信/电话/视频）
适用场景：
- 业主有一定谈判能力
- 合同相对简单
- 预算有限
定价：
- 买过审合同：1000积分
- 没买过：2500积分
```

#### 服务流程

##### 阶段1：预约下单（T-1至T-2天）
```
业主预约时填写：
□ 装企名称
□ 预计签约时间（XX月XX日XX点）
□ 签约地点（装企办公室/业主家）
□ 是否买过审合同服务
□ 特殊说明（有什么特别关注的点）

平台派单：
- 提前1-2天派单
- 优先派懂合同的人（律师、法务、资深从业者）
- 优先派评分≥4.8的陪签人
```

##### 阶段2：陪签人准备（T-1天）
```
如果买过审合同：
□ 调出业主的审核报告（看之前发现了什么问题）
□ 调出验房报告、实测图
□ 联系业主确认（1天前电话/微信）
  "王姐，我明天陪您签合同，
  确认一下：明天下午2点，
  您在装企办公室对吗？
  
  我看了您之前的审核报告，
  发现了5个问题，
  您跟装企谈了吗？改了几个？
  
  明天签约时，
  您拍照发给我，我在线看，
  15-30分钟内给您反馈。"

如果没买过审合同：
□ 研究装企合同模板
□ 准备审核清单
□ 联系业主确认
  "王姐，我明天陪您签合同。
  
  因为您没有做过审合同服务，
  我会在现场帮您审一遍合同，
  但没有实测数据对照，
  只能凭经验判断。
  
  建议您把装企的报价单、设计图纸
  都拍给我，我提前看一下。"
```

##### 阶段3：签约当天线上陪签（T日，1-1.5小时）
```
签约时间到，陪签人在线待命

业主到装企办公室：
- 拿到最终版合同
- 拍照/扫描发给陪签人（微信）

陪签人审核（15-30分钟）：

【如果买过审合同】
□ 对照审核报告逐项检查：
  - 问题1（面积虚报）改了吗？改对了吗？
  - 问题2（水电改造不透明）改了吗？
  - 问题3（材料没写型号）改了吗？
  - ...

□ 对照实测数据核对：
  - 合同面积 vs 实测面积
  - 拆改项目 vs 承重墙标注
  - 水电改造工程量 vs 实际点位

□ 检查有没有新增问题：
  - 改了旧问题，会不会加了新坑

□ 检查模糊细节：
  - 材料品牌有没有写明型号
  - 付款节点具体是哪天
  - 工期从哪天算起、延期怎么赔偿

【如果没买过审合同】
□ 从头审合同（相当于现场做一次审合同）
  - 总价是否清晰
  - 增项条款
  - 付款节点
  - 工期约定
  - 材料品牌型号
  - 质保条款
  - 违约责任

□ 审报价单：
  - 单价是否合理（对照市场价）
  - 有没有重复项
  - 有没有漏项

□ 看设计图纸：
  - 方案是否合理
  - 但无法核对是否符合实际户型（没有实测图）

陪签人反馈（微信/电话，15-30分钟）：
"王姐，合同我看完了，
有X个问题需要注意：

【如果买过审合同】
问题1（之前审出的）：面积虚报
- 之前审核报告里说合同写92㎡，实测89㎡
- 现在合同改成89㎡了吗？
- 我看了一下，改了，但报价还是按92㎡算的
- 您要求装企把报价也改成89㎡

问题2（之前审出的）：水电改造不透明
- 之前建议改成"超预算10%要签字"
- 现在改了吗？
- 我看了一下，没改，还是"按实际发生"
- 您再跟装企争取一下，
  实在不行，至少要个预估总价

问题3（新发现的）：材料型号不明确
- 合同写"圣象地板"，但没写型号
- 建议您要求写明"圣象XX系列XX型号，参考价XX元/㎡"

【如果没买过审合同】
问题1：面积可能虚报
- 合同写92㎡，但您的产权证是多少？
- 如果产权证也是92㎡，那可能没问题
- 但实际可用面积可能小于产权证面积
- 建议您让装企按实际施工面积结算

问题2：水电改造不透明
- 合同写"按实际发生"
- 这是增项重灾区
- 建议您要求装企给个预估总价
  或者写明"超预算10%要签字"

...

您现在可以拿着这些问题跟装企谈，
我在线等着，
您谈完告诉我结果，
我再帮您看看改得对不对。"

业主跟装企谈（30分钟）：
- 业主拿着陪签人的反馈跟装企谈
- 装企改合同 or 解释 or 拒绝改

业主再次发给陪签人：
- 改完的合同拍照发给陪签人

陪签人确认（10分钟）：
"王姐，改完的合同我看了，
问题1改对了，
问题2装企不愿意改，但承诺了预估总价3万，
您能接受的话，可以在合同里补充一条：
'水电改造预估总价3万，超过10%需签字确认'

问题3也改了，写明了型号。

没有其他问题了，可以签。

签字前记得：
- 每页都签字
- 留一份原件
- 拍照存档

签完发给我，我帮您最后确认一下。"

业主签字、拍照发给陪签人

陪签人最后确认（5分钟）：
"王姐，合同签完了，我看了一下，
每页都签了，没问题。

后续注意：
- 开工前3天装企会通知您
- 记得让装企出详细的施工图
- 开工后可以使用洞居的监理服务

祝您装修顺利！"
```

```

让业主心里有个底。

'水电改造预估3万，超过10%需签字确认'

【如果没买过审合同】
陪签人从头审合同：

合同写"按实际发生"，

或者写明超预算多少需要签字？
...（谈判）

...（逐项审核、谈判）"

明确细节（20-30分钟）：
陪签人逐条确认模糊的地方：

"材料品牌型号：
- 合同写'圣象地板'，具体哪个系列、哪个型号？
- 参考价多少？
- 麻烦写在合同里，或者附件清单里写明。

开工时间：
- 合同写'X月X日开工'，具体几点？
- 如果业主那天有事，能不能提前一天通知？

- 首付3万，什么时候付？签合同当天吗？

  谁验收？业主验收还是第三方验收？

- 合同写90天，从开工算起还是签合同算起？
- 如果延期，每天赔偿多少？

...（把所有模糊的地方都明确）"

如果装企坚持不改某些条款：

陪签人判断：
- 这个条款重要吗？
- 重要 → 坚持要求改
- 不重要 → 建议业主让步

- 每页都要签字或按手印

"王姐，合同签完了。
```

## 三、核心价值与边界

### 3.1 陪签的三大核心价值

#### 价值1：确认修改落地
```
审合同阶段发现的问题，
装企真的改对了吗？

例：
- 审合同发现"面积虚报"
- 业主跟装企谈，装企说"改了"
- 陪签人确认：真的改了吗？改对了吗？
  有没有改了面积，但报价还是按原面积算？
```

#### 价值2：明确模糊细节
```
合同里经常有模糊的地方，
陪签人帮业主"把模糊变明确"

例：
- "圣象地板" → 哪个系列？哪个型号？多少钱？
- "按实际发生" → 预估多少？超多少要签字？
- "工期90天" → 从哪天算？延期怎么赔偿？
- "保修2年" → 从哪天算？保修范围是什么？

这些细节不明确，后期容易扯皮
```

#### 价值3：推进签约
```
帮业主和装企达成一致，顺利签约

例：
- 业主坚持要改A条款，装企坚持不改
- 陪签人判断：这个条款重要吗？
  - 重要 → 支持业主，坚持要改
  - 不重要 → 建议业主让步，推进签约
- 或者找折中方案：
  "这条不能改，能不能改成XX？"
```

---

### 3.2 陪签的服务边界

#### ✅ 陪签人可以做的
```
✓ 确认之前的问题改了没
✓ 明确模糊细节
✓ 代为谈判（跟装企沟通修改）
✓ 给业主建议（哪些要坚持、哪些可以让步）
✓ 推进签约（帮双方达成一致）
✓ 拍照存档
```

#### ❌ 陪签人不做的
```
✗ 不现场重新找茬（找茬是审合同阶段的事）
✗ 不承诺砍价（砍价是陪谈单阶段的事）
✗ 不替业主签字（签字权在业主）
✗ 不替业主做决策（只给建议，业主自己决定）
```

---

### 3.3 关于砍价的处理

#### 明确告知业主
```
产品页 + 服务前沟通：

"陪签服务的核心价值是：
1. 确认合同条款改对了
2. 明确模糊细节
3. 推进签约

砍价不是陪签的主要服务，
因为：
- 砍价应该在'陪谈单'阶段进行
- 到了签约阶段，价格基本定了
- 这时候再砍价,装企很难让步

如果您还没跟装企谈价格，
建议先使用'陪谈单'服务，
谈好价格再来签。"
```

#### 如果签约现场业主还想砍价
```
业主："价格还是有点贵，能不能再便宜点？"

陪签人回答：

方案1：支持试探性砍价
"您可以试试跟装企说：
'价格能不能再优惠一点？
或者送点东西（免费设计、免费监理）？'

但别抱太大期望，
因为到了签约阶段，
装企一般不会再降价了。"

方案2：转移到赠品/服务
"价格可能改不了，
但您可以试试要点赠品或服务：
- 免费出3D效果图
- 免费做个柜子
- 免费升级某个材料
这样装企更容易接受。"

方案3：如果价格明显偏高
"您这个报价确实偏高，
市场价应该在XX-XX万，
您这个报了XX万。

建议您可以跟装企说：
'我对比了几家，你们价格偏高，
能不能降到XX万？
如果不行，我再考虑考虑。'

如果装企不降，
我建议您再比比其他家。"

核心原则：
- 支持合理砍价
- 不承诺一定砍下来
- 不强行砍价（避免关系搞僵）
```

## 四、陪签人管理

### 4.1 陪签人资质

#### 准入要求
```
硬性条件：
□ 装修从业经验≥5年
□ 懂合同（有法务经验 or 签过很多合同）
□ 会谈判（口才好、敢说话）
□ 无不良记录

软性条件：
□ 沟通能力强
□ 服务意识好
□ 专业可信
□ 洞居培训合格
```

#### 培训考核（2天）

### 4.2 派单规则
```
优先级：
1. 懂这个装企合同的人（陪签过这家装企）
2. 评分≥4.8的陪签人
3. 距离签约地点≤10公里的陪签人
4. 本月服务量<10单的陪签人
```

### 4.3 收入机制
```
线上陪签：
- 买过审合同：1000积分，陪签人得80-100元
- 没买过：2500积分，陪签人得150-200元

线下陪签：
- 买过审合同：1500积分，陪签人得120-150元
- 没买过：3000积分，陪签人得200-250元

注：没买过审合同的服务费高，
因为相当于现场做一次审合同+陪签，
工作量大、耗时长
```

### 4.4 质量管控
```
业主评价：
□ 是否确认了问题改对
□ 是否明确了模糊细节
□ 是否帮助推进签约
□ 服务态度
□ 总体满意度

抽检机制：
- 新陪签人：100%抽检（前5单）
- 老陪签人：20%随机抽检

抽检方式：
- 电话回访业主
- 查看签约后的合同
- 现场暗访（合伙人扮演业主）
```

## 七、总结

### 7.1 核心价值
```
业主：
- 确认合同改对了（避免扯皮）
- 明确模糊细节（后期不扯皮）
- 有人撑腰（不怕装企忽悠）
- 顺利签约

陪签人：
- 获得服务费收入
- 建立专业形象

平台：
- 服务闭环（验房→审合同→陪签→监理）
- 建立信任
- 口碑传播
```

### 7.2 关键成功要素
```
1. 定位清晰
   - 陪签 = 确认落地 + 明确细节 + 推进签约
   - 不是找茬、不是砍价

2. 分层定价
   - 买过审合同：便宜（有数据支撑，专业）
   - 没买过：贵（鼓励买前置服务）

3. 服务边界清晰
   - 做什么、不做什么
   - 提前告知业主

4. 专业可信
   - 陪签人懂合同、会谈判
   - 能推进双方达成一致
```

### 7.3 一句话总结
> **确认落地，明确细节，安心签约**  
> 不是找茬，是确认；不是砍价，是落地
