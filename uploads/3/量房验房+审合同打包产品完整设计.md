# 量房验房+审合同打包产品完整设计

## 一、产品定位与逻辑

### 1.1 产品名称
**"新房把关套餐"** or **"装修合同审核套餐"**

Slogan：**"签合同前，先把房子摸清楚"**

### 1.2 核心逻辑

#### 业主真实痛点
```
❌ 不是："我要验房"
✅ 而是："我怕签合同被坑"

装修最大的坑 = 合同签了，后面被动
→ 增项、材料偷换、工期延误，都因为合同没审好
```

#### 为什么要打包验房+审合同？
```
审合同不是只看文字条款，需要对照房屋实际情况：

问题1：拆改工程报价合理吗？
→ 需要知道：哪些墙是承重墙

问题2：水电改造报价合理吗？
→ 需要知道：现有水电点位在哪，要改多少

问题3：面积计价对不对？
→ 需要知道：实际面积是多少（不是产权证面积）

问题4：材料数量算得对吗？
→ 需要知道：门窗尺寸、地面面积

结论：
审合同的前提 = 必须有准确的房屋数据
→ 这个数据从哪来？从量房验房来！
→ 所以打包是必然，不是强行捆绑
```

#### 三方价值
```
业主：
- 验房发现问题，避免交房纠纷
- 审合同避坑，避免装修被坑
- 有实测数据，心里有底

装企：
- 上门见业主，建立第一印象
- 审合同时还能再接触，延长转化周期
- 专业背书（东易日盛 X 洞居）

平台：
- 采集数据（户型、需求、预算）
- 建立信任（专业、靠谱）
- 服务闭环（验房→审合同→陪签单→监理）
```

## 二、服务内容与流程

### 2.1 第一阶段：验房量房（线下，90分钟）

#### 服务内容
```
1. 验房动作（30-40分钟）
   - 检查房屋质量（墙面、地面、门窗、水电）
   - 发现问题，给整改建议
   - 拍照记录（20-30张）

2. 量房动作（30-40分钟）
   - 精确测量尺寸（激光测距仪）
   - 手绘户型图（iPad现场画）
   - 标注承重墙、梁柱、水电点位
   - 记录关键尺寸

3. 需求沟通（15-20分钟）
   - 了解装修预算、时间、风格
   - 了解家庭成员、生活习惯
   - 了解功能需求（衣帽间、书房...）
```

#### 交付物（当天，微信发送）
```
1. 验房报告.pdf（8-12页）
   - 房屋基本信息
   - 问题汇总表
   - 逐项检查详情（照片+说明）

2. 户型实测图.pdf（2-3页）
   - 手绘户型图照片
   - 精确尺寸标注（误差≤10mm）
   - 承重墙标注（红色粗线）
   - 水电点位标注
   - 关键尺寸汇总表

3. 装修启动清单.pdf（1页）
   - 房子基本情况
   - 装修第一步建议
   - 避坑提醒
   - 后续服务介绍
```

#### 服务话术（结束时）
```
验房师：
"王姐，今天的验房量房完成了。
明天您会收到验房报告和实测图。

特别提醒您，这个实测图很重要，
您接下来找装修公司报价，
拿到报价和合同后，
一定要发给我们审一下。

很多装企会虚报面积、虚报工程量，
我们有实测数据，一对照就知道了。

审合同服务包含在这个套餐里，
您随时把合同发给洞居管家，
我们会安排专业人帮您审，
1-2天就能给您反馈。"
```

### 2.2 第二阶段：审合同（线上，1-2天交付）

#### 触发时机
```
业主拿到装企报价和合同
→ 微信发给洞居管家
→ 管家转给审核员
→ 1-2天内出审核报告
```

#### 审核内容（对照实测数据）
```
1. 面积计价审核（核心）
   - 合同面积 vs 实测面积
   - 是否虚报面积
   - 建议按实测面积计价

2. 工程量审核
   - 拆改项目：对照承重墙标注
   - 水电改造：对照现有水电点位
   - 防水面积：对照厨卫实际面积
   - 瓷砖面积：对照地面实际面积
   - 门窗数量：对照实际数量

3. 单价审核
   - 对照本地市场价
   - 标注偏高的项目
   - 给出合理价格区间

4. 合同条款审核
   - 总价是否清晰
   - 增项条款（超预算怎么算）
   - 付款节点（建议3-3-3-1）
   - 工期约定（延期怎么赔偿）
   - 材料品牌型号（是否写清楚）
   - 质保条款（保修几年）
   - 违约责任

5. 漏项识别
   - 对照验房报告
   - 发现的质量问题，合同里有没有整改费用
   - 例：防水不合格，合同里有没有重做防水
```

```

□ 提前1天给业主发短信提醒
```

#### 现场服务（T日，90分钟）
```
0-10分钟：到场准备
□ 提前10分钟到达
□ 穿洞居工服/佩戴工牌
□ 开场白（介绍服务内容）

□ 按房间逐个检查（客厅→主卧→次卧→厨房→卫生间→阳台）

□ 发现问题拍照+红笔标注
□ iPad记录问题

40-70分钟：量房动作
□ 激光测距仪测量尺寸（每个尺寸测3次取平均）
□ iPad手绘户型图
□ 标注承重墙、梁柱、水电点位
□ 记录关键尺寸

70-85分钟：需求沟通
□ 装修预算
□ 启动时间
□ 风格偏好
□ 家庭成员
□ 功能需求

85-90分钟：结束话术
□ 总结房子情况
□ 告知交付物（明天收到）
□ 强调审合同服务（包含在套餐里）
□ 发名片，留联系方式
```

#### 数据上传（T日18:00前）
```
□ 上传照片（20-30张）
□ 上传手绘图照片
□ 上传问题清单（结构化数据）
```

### 3.2 审合同SOP

#### 业主提交合同（触发审核）
```
业主把装企报价和合同发给管家
→ 管家接收并登记
→ 分配给审核员
→ 审核员1-2天内完成
```

#### 审核流程（审核员，1-2小时）
```
1. 读取实测数据
   □ 调出该业主的验房报告
   □ 调出户型实测图
   □ 准备面积对比表模板

2. 面积审核（核心）
   □ 对比合同面积 vs 实测面积
   □ 逐项对比（客厅、卧室、厨房、卫生间）
   □ 计算差异金额
   □ 填写面积对比表.xlsx

3. 工程量审核
   □ 拆改项目：对照承重墙标注
     - 合同要拆的墙，是不是承重墙
     - 承重墙不能拆，非承重墙可以拆
   
   □ 水电改造：对照水电点位图
     - 现有插座X个，合同要增加Y个
     - 现有灯位X个，合同要增加Y个
     - 计算改造量是否合理
   
   □ 防水面积：对照实测厨卫面积
     - 合同写防水X㎡，实测只有Y㎡
   
   □ 瓷砖面积：对照实测地面面积
     - 合同写瓷砖X㎡，实测只有Y㎡

4. 单价审核
   □ 对照本地市场价数据库
   □ 标注偏高的项目（>市场价20%）
   □ 给出合理价格区间

5. 合同条款审核
   □ 总价是否清晰（有没有"暂定价"）
   □ 增项条款（超预算怎么算）
   □ 付款节点（是否合理）
   □ 工期约定（有没有延期赔偿）
   □ 材料品牌型号（是否写清楚）
   □ 质保条款（保修几年、范围）
   □ 违约责任（谁违约怎么赔）

6. 漏项识别
   □ 对照验房报告
   □ 发现的质量问题，合同里有没有整改费用
   □ 例：墙面空鼓，合同里有没有铲墙找平

7. 风险分级
   □ 🔴 高风险：必须改（面积虚报、增项不透明）
   □ 🟡 中风险：建议改（材料不明确、付款不合理）
   □ 🟢 低风险：提醒（工期没约束）
```

#### 制作审核报告（30-60分钟）
```
□ 套用合同审核报告模板
□ 填写审核结论
□ 填写问题清单（逐条）
□ 插入面积对比表
□ 填写修改建议
□ 填写谈判话术
□ 转PDF
□ 审核质量
```

#### 交付与跟进
```
□ 管家微信发送报告给业主
□ 电话/语音讲解重点问题（5-10分钟）
□ 询问是否需要陪签单服务
□ 记录业主反馈
□ 3天后回访（合同改了吗、签了吗）
```

## 六、关键成功要素

### 6.1 验房阶段
```
✓ 装企必须是本地知名品牌（业主听过）
✓ 服务必须专业（17件设备、标准流程）
✓ 必须强调审合同（结束时留钩子）
✓ 数据必须准确（审合同要用）
```

### 6.2 审合同阶段
```
✓ 必须对照实测数据（体现打包价值）
✓ 必须发现真问题（不能敷衍）
✓ 必须给谈判话术（业主拿着能用）
✓ 必须引导陪签单（后续服务衔接）
```

### 6.3 体验优化
```
✓ 交付要快（验房当天、审合同1-2天）
✓ 讲解要清晰（管家电话讲解重点）
✓ 文档要实用（业主看得懂、用得上）
✓ 跟进要及时（3天后回访）
```
