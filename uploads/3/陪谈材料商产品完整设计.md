# 陪谈材料商产品完整设计

## 一、产品定位

### 1.1 产品名称
**"主材陪选服务"** or **"材料陪谈服务"**

Slogan：**"不替你选，只帮你懂"**

### 1.2 核心定位

#### 业主痛点
```
"我要去买地砖/橱柜/卫浴，
但我不懂材料、看不懂参数、不知道价格合不合理，
怕被导购忽悠，想找个懂行的人陪我去看。"
```

#### 洞居方案
```
派一个懂材料的人（设计师/工作室/资深从业者）
陪业主去建材市场/家居商场，
现场讲解材料知识、对比价格行情，
但不做推荐、不替业主决策，
只给客观信息，由业主自己选。
```

### 1.3 服务边界（核心原则）

#### ✅ 接单人做的事（教练角色）
```
1. 讲解材料知识
   - 这是什么材料
   - 有什么特点
   - 适合什么场景
   - 参数代表什么意思

2. 对比价格行情
   - 市场价是多少
   - 这个报价偏高还是偏低
   - 这个价格包含什么

3. 客观对比
   - A店和B店的区别
   - 不同材料的特点对比
   - 不同价格的配置对比

4. 回答问题
   - 业主问什么，客观回答
   - 解释专业术语
   - 澄清导购的话
```

#### ❌ 接单人不做的事（不做决策者）
```
1. 不推荐
   ✗ "我建议您买这家"
   ✗ "这家最适合您"
   ✗ "您就买这个吧"

2. 不总结引导
   ✗ "综合来看，XX最合适"
   ✗ "性价比最高的是XX"
   ✗ "如果是我，我选XX"

3. 不主观评价
   ✗ "这家最好"
   ✗ "那家不行"
   ✗ "这款比那款好"

4. 不替业主决策
   ✗ 直接告诉业主买哪个
```

## 二、服务内容与流程

### 2.1 服务参数

#### 基本参数
```
服务时长：3小时
服务范围：单一品类（地砖 or 木地板 or 橱柜 or 卫浴）
服务方式：线下陪同
服务人数：1对1（1个接单人陪1个业主）
定价：1500积分 or 200元
```

#### 适用品类
```
主材类：
- 地面材料：地砖、木地板、地板砖
- 墙面材料：墙砖、墙纸、墙布
- 定制类：橱柜、衣柜、榻榻米
- 卫浴类：马桶、花洒、浴室柜、五金
- 门窗类：木门、窗户、推拉门
- 吊顶类：集成吊顶、石膏板

不含：
- 辅材（水泥、沙子、腻子等）
- 家具（沙发、床、桌椅）
- 家电（冰箱、洗衣机、电视）
```

### 2.2 完整服务流程

#### 阶段1：预约下单（T-2天）

**业主下单时填写：**
```
必填信息：
□ 要买什么材料（地砖/木地板/橱柜/卫浴...）
□ 装修空间（客厅/卧室/厨房/卫生间...）
□ 大概面积
□ 心理预算
□ 准备去哪几家店看（店名或商场名）
□ 预约时间和碰面地点

选填信息：
□ 特殊需求（防滑/环保/静音...）
□ 风格偏好（现代/北欧/中式...）
```

**系统派单：**
```
派单规则：
- 优先派懂这个品类的接单人（设计师/材料专家）
- 优先派熟悉这个商场的接单人
- 优先派评分≥4.8的接单人
- 本月服务量<15单的接单人
```

#### 阶段2：接单准备（T-1天）

**接单人接单后：**
```
1. 查看订单详情（15分钟）
   □ 业主要买什么材料
   □ 预算多少
   □ 去哪几家店
   □ 有什么特殊需求

2. 联系业主确认（30分钟）
   电话或微信：
   "王姐，我是洞居派来陪您看地砖的，
   周六下午2点，红星美凯龙门口见对吧？
   
   我这边需要确认一下：
   - 您准备去哪几家店看？
     （如果业主不知道，可以建议：
     "地砖通常大家看马可波罗、东鹏、诺贝尔这几家，
     您可以考虑一下"）
   
   - 您的预算大概是多少？
   - 客厅多少平方？
   
   这样我能提前帮您做点功课，
   到时候讲解会更清楚。"

3. 做功课（1-2小时）
   □ 研究这几家品牌
     - 品牌特点（一线/二线、定位、风格）
     - 主打产品（哪些系列、哪些型号）
     - 价格区间（市场价大概多少）
     - 口碑评价（质量、售后怎么样）
   
   □ 研究这类材料的选购知识
     - 关键参数有哪些（吸水率、耐磨度...）
     - 怎么看好坏（看哪里、摸哪里）
     - 常见坑有哪些（导购会怎么忽悠）
   
   □ 准备对比表格（iPad或纸质）
     - 品牌、型号、价格、特点、包含内容
   
   □ 准备选购清单
     - 这类材料的10个关键看点
```

#### 阶段3：现场陪同（T日，3小时）

**时间分配：**
```
0-15分钟：碰面沟通
15-165分钟：逛店对比（3-5家店，每家30-45分钟）
165-180分钟：总结答疑（不做引导，只答疑）
```

**详细流程：**

##### 3.1 碰面沟通（0-15分钟）
```
地点：商场门口

接单人：
"王姐您好，我是洞居派来的陪谈师XX，
今天陪您看地砖。

我先说明一下我的角色：
我的作用是帮您了解材料的知识和价格行情，
现场给您讲解、对比，
但最后买哪家、买哪款，
是您自己决定，我不会给您推荐。

您有什么问题吗？
没有的话我们开始吧。"

（设置预期，避免业主后面问"你觉得哪个好"）
```

##### 3.2 第一家店（15-60分钟，45分钟）
```
进店 → 看产品 → 问价格 → 讲解 → 记录 → 离店

【进店】
接单人不主动说话，跟着业主和导购

【看产品】
业主："我想看看抛光砖"
导购："这款是我们的XX系列，150元/㎡"

接单人（讲解材料知识）：
"王姐，这款是抛光砖，
我给您讲一下抛光砖的特点：
- 表面光滑，亮度高
- 易清洁，好打理
- 但防滑性一般，适合客厅，卫生间不太适合

您看这个砖的背面（翻过来给业主看），
这些参数代表什么：
- 吸水率0.5%：数值越低越好，这个是优等品
- 耐磨度4级：最高5级，这个算不错的
- 尺寸800×800mm：常见规格

您可以摸一下表面（引导业主自己感受），
光滑度怎么样？"

【问价格】
业主问或接单人提醒业主问：
"这款多少钱？包含什么？"

导购："150元/㎡，包送货不包安装"

接单人（对比价格行情）：
"这个价格我解释一下：
- 市场价：抛光砖一般在120-180元/㎡
- 这个报价：150元，在中等偏上
- 包含：瓷砖本身 + 送货（市内）
- 不含：安装费（一般20-30元/㎡另算）

您可以记一下，
咱们看完几家再对比。"

【记录】
接单人在iPad上填对比表：
□ 品牌：马可波罗
□ 型号：XX系列抛光砖
□ 价格：150元/㎡
□ 包含：砖 + 送货
□ 特点：光滑易清洁，防滑性一般
□ 参数：吸水率0.5%，耐磨4级
□ 备注：适合客厅

【离店】
看完这家，去下一家
路上可以简单聊：
"刚才那款您感觉怎么样？
有没有什么疑问？"
（不做评价，只答疑）
```

##### 3.3 第二家店（60-105分钟，45分钟）
```
同样流程：
进店 → 看产品 → 讲解（仿古砖的特点）→ 问价格 → 对比行情 → 记录

接单人会对比两家：
"这家是仿古砖，
刚才那家是抛光砖，
两种砖的特点不一样：
- 抛光砖：光滑，适合客厅
- 仿古砖：防滑，适合卫生间和阳台

您想要哪种？"

（对比事实，不做推荐）
```

##### 3.4 第三家店（105-150分钟，45分钟）
```
同样流程

如果业主看累了，可以提议：
"要不要先坐下来休息一下，
我把前面看的几家给您对比一下？"
```

##### 3.5 总结答疑（150-180分钟，30分钟）
```
找个地方坐下（商场休息区/咖啡厅）

接单人拿出对比表：
"王姐，咱们看了3家，
我把对比表给您看一下：

【对比表】（iPad展示或纸质）
┌─────────────────────────────────┐
│        马可波罗   东鹏     诺贝尔   │
├─────────────────────────────────┤
│ 类型    抛光砖    仿古砖   进口砖   │
│ 价格    150      120      180元/㎡ │
│ 市场价  120-180  80-150   150-250 │
│ 价格水平 中偏上   中等     中偏低   │
│ 包含    砖+送货  砖+送货  砖+送货   │
│ 特点    光滑易清洁 防滑   设计感强  │
│ 适用    客厅     客厅卫生间 客厅    │
│ 参数    吸水率0.5% 吸水率0.8% ...  │
└─────────────────────────────────┘

客厅30㎡的话：
- 马可波罗：150×30=4500元
- 东鹏：120×30=3600元
- 诺贝尔：180×30=5400元

（客观陈述，不做评价）

您有什么问题吗？
或者哪个地方需要我再解释一下？"

【如果业主问："你觉得我应该买哪个？"】

接单人（不给主观意见）：
"这个真的要看您自己的需求和喜好。

我只能告诉您客观情况：
- 质量上：3家都是一线品牌，差别不大
- 价格上：东鹏最便宜，诺贝尔最贵
- 类型上：
  抛光砖光滑易清洁（马可波罗、诺贝尔）
  仿古砖防滑（东鹏）
- 款式上：您自己看哪个喜欢

我的作用是帮您了解这些区别，
但最后选哪个，还是您自己决定。

因为装修是您家，您住进去要舒服，
我不能替您做决定。

您可以回去再想想，
或者下次再来看看其他款。"

【如果业主确定要买某一家】

接单人：
"好的，那您准备买这家。
我帮您再看一下：

- 价格：XX元/㎡
- 包含：砖 + 送货
- 不含：安装（需要另算）
- 数量：30㎡，建议多买5%-10%，
  避免不够或有损耗

您准备下单吗？
需要我帮您看一下订单吗？"

（陪同看订单，避免坑）
```

## 三、标准化设计

### 3.1 对比表标准格式

#### 通用对比维度
```
1. 基本信息
   - 品牌
   - 型号/系列
   - 产地（国产/进口）

2. 价格信息
   - 报价（元/㎡ or 元/延米 or 元/套）
   - 市场价区间
   - 价格水平（偏高/中等/偏低）
   - 包含内容（送货/安装/配件）

3. 产品特点
   - 材质类型
   - 核心特点（3-5个）
   - 适用场景
   - 关键参数

4. 服务信息
   - 质保期
   - 售后政策
   - 送货周期

5. 备注
   - 特殊说明
   - 需要注意的点
```

#### 分品类对比要点

**地砖对比要点：**
```
□ 类型（抛光砖/仿古砖/釉面砖/通体砖）
□ 尺寸规格（800×800/600×600）
□ 吸水率（越低越好，<0.5%是优等品）
□ 耐磨度（1-5级，越高越好）
□ 防滑性（R值，R9-R13）
□ 色差（大批次色差情况）
□ 平整度（误差≤2mm）
□ 适用场景（客厅/卫生间/阳台）
□ 价格（元/㎡）
□ 包含内容（送货/安装/配件）
```

**木地板对比要点：**
```
□ 类型（实木/实木复合/强化）
□ 厚度（8mm/12mm/15mm）
□ 环保等级（E0/E1）
□ 耐磨转数（家用≥6000转）
□ 甲醛释放量（mg/L）
□ 防水性（能不能用地暖）
□ 锁扣方式（免胶/打胶）
□ 颜色花纹
□ 适用场景（客厅/卧室）
□ 价格（元/㎡）
□ 包含内容（地板/辅料/安装）
```

**橱柜对比要点：**
```
□ 柜体材质（实木/颗粒板/多层板）
□ 台面材质（石英石/不锈钢/岩板）
□ 门板材质（实木/烤漆/吸塑/亚克力）
□ 五金品牌（国产/进口，品牌名）
□ 环保等级（E0/E1）
□ 设计方案（L型/U型/一字型）
□ 包含内容（吊柜/地柜/台面/水槽/五金）
□ 价格（元/延米）
□ 安装周期
```

**卫浴对比要点：**
```
□ 类型（智能马桶/普通马桶）
□ 排水方式（地排/墙排）
□ 冲水方式（直冲/虹吸）
□ 节水性（3L/4.5L/6L）
□ 釉面质量（易清洁性）
□ 智能功能（加热/除臭/烘干）
□ 尺寸（坑距300/400mm）
□ 价格（元/套）
□ 包含内容（马桶/水箱/配件/安装）
```

### 3.2 选购指南内容框架

#### 以地砖为例
```
┌─────────────────────────────────┐
│ 地砖选购指南                     │
│ 洞居 材料知识库                  │
├─────────────────────────────────┤
│                                 │
│ 一、地砖的分类                   │
│                                 │
│ 1. 抛光砖                        │
│ 特点：光滑、亮度高、易清洁        │
│ 适用：客厅、餐厅                 │
│ 不适用：卫生间（防滑性差）        │
│                                 │
│ 2. 仿古砖                        │
│ 特点：防滑、有纹理、有质感        │
│ 适用：客厅、卫生间、阳台          │
│ 不适用：对亮度要求高的空间        │
│                                 │
│ 3. 釉面砖                        │
│ 特点：图案丰富、防污性好          │
│ 适用：墙面、小面积装饰            │
│ 不适用：地面（耐磨性差）          │
│                                 │
│ ...                             │
│                                 │
│ 二、地砖的10个关键参数           │
│                                 │
│ 1. 吸水率（越低越好）             │
│ 优等品：≤0.5%                   │
│ 一等品：0.5%-3%                 │
│ 合格品：3%-10%                  │
│ 怎么看：看砖背面的标识            │
│                                 │
│ 2. 耐磨度（越高越好）             │
│ 1级：轻度磨损（不建议地面）       │
│ 2-3级：中度磨损（家用可以）       │
│ 4-5级：重度磨损（家用最佳）       │
│ 怎么看：用钥匙刮表面，看划痕       │
│                                 │
│ 3. 防滑性（R值越高越防滑）        │
│ R9：轻度防滑（干燥地面）          │
│ R10-R11：中度防滑（家用推荐）     │
│ R12-R13：重度防滑（卫生间推荐）   │
│ 怎么测：在砖上洒水，光脚踩一下     │
│                                 │
│ ...（共10个参数）                │
│                                 │
│ 三、选购地砖的5个步骤             │
│                                 │
│ 步骤1：确定类型                  │
│ 客厅 → 抛光砖/仿古砖             │
│ 卫生间 → 仿古砖（防滑）          │
│ 阳台 → 仿古砖                   │
│                                 │
│ 步骤2：确定尺寸                  │
│ 客厅 → 800×800mm（大气）        │
│ 卫生间 → 300×300mm（好找坡度）  │
│ 阳台 → 600×600mm                │
│                                 │
│ ...                             │
│                                 │
│ 四、常见的5个坑                  │
│                                 │
│ 坑1：只看价格不看等级             │
│ 同样是马可波罗，                 │
│ 优等品和一等品价格差一倍，         │
│ 导购不会主动告诉您等级。          │
│ 避坑：看砖背面的等级标识          │
│                                 │
│ 坑2：只买够面积不留损耗           │
│ 铺砖有损耗（切割、破损），        │
│ 一般要多买5%-10%，               │
│ 否则后期补货可能有色差。          │
│ 避坑：按实际面积×1.1计算          │
│                                 │

### 3.3 接单人话术培训

#### 核心话术原则
```
1. 讲事实，不评价
   ✓ "这款是抛光砖，特点是光滑易清洁"
   ✗ "这款最好"

2. 给对比，不推荐
   ✓ "A店这款150元，B店这款120元"
   ✗ "B店便宜，买B店的"

3. 说市场价，不砍价
   ✓ "市场价120-180元，这个报价150元，在中等"
   ✗ "这个太贵了，你砍到120元"

4. 答疑问，不决策
   ✓ "您问的这两款区别是……"
   ✗ "您买这款吧"
```

#### 标准话术模板

**开场话术：**
```
"XX姐/哥，您好，我是洞居派来的陪谈师XX。

今天陪您看XX（地砖/橱柜/卫浴），
我先说明一下我的角色：

我的作用是帮您了解材料的知识和价格行情，
现场给您讲解、对比，
但最后买哪家、买哪款，是您自己决定，
我不会给您推荐。

您有什么问题吗？
没有的话我们开始吧。"
```

**讲解材料话术：**
```
"这款是XX（材料类型），
我给您讲一下它的特点：
- 特点1：……
- 特点2：……
- 适用场景：……
- 不适用场景：……

您看这个参数（指着标识），
XX代表XX，数值越XX越好，
这个是XX等级。

您可以摸一下/看一下（引导业主自己感受），
感觉怎么样？"
```

**对比价格话术：**
```
"这个价格我解释一下：
- 市场价：XX材料一般在XX-XX元
- 这个报价：XX元，在XX水平（偏高/中等/偏低）
- 包含：XX + XX
- 不含：XX（一般XX元另算）

您可以记一下，咱们看完几家再对比。"
```

**对比不同店话术：**
```
"咱们现在看了X家了，我给您对比一下：

A店：
- 类型：XX
- 价格：XX元
- 特点：……

B店：
- 类型：XX
- 价格：XX元
- 特点：……

两家的区别是：
- 类型不同：A是XX，B是XX
- 价格不同：A比B贵XX元
- 特点不同：A是……，B是……

（客观对比，不做评价）

您有什么想问的吗？"
```

**被追问"你觉得呢"话术：**
```
业主："你觉得我应该买哪个？"

接单人：
"XX姐/哥，这个真的要看您自己的需求和喜好。

我只能告诉您客观情况：
- 质量上：……
- 价格上：……
- 特点上：……
- 适用上：……

我的作用是帮您了解这些区别，
但最后选哪个，还是您自己决定。

因为装修是您家，您住进去要舒服，
我不能替您做决定。

您可以想想您更看重什么？
是价格、质量、还是款式？"
```

### 3.4 边界红线培训

#### 红线清单（说了就违规）
```
❌ 禁止话术1：推荐
"我建议您买这家"
"这家最适合您"
"您就买这个吧"
"如果是我，我选这个"

❌ 禁止话术2：总结引导
"综合来看，XX最合适"
"性价比最高的是XX"
"XX最划算"

❌ 禁止话术3：主观评价
"这家最好"
"那家不行"
"这家质量比那家好"
"这款比那款强"

❌ 禁止话术4：诋毁品牌
"这个品牌是垃圾"
"这家经常出问题"
"这个牌子别买"

❌ 禁止话术5：替业主决策
"您别想了，就买这个"
"听我的，买那个"
"相信我，这个好"
```

#### 违规处罚
```
轻微违规（说了1-2句推荐话术）：
- 业主评价扣分
- 扣服务费20%
- 警告

严重违规（多次推荐、诋毁品牌、拿回扣）：
- 业主评价1星
- 扣服务费100%
- 暂停派单1个月

重大违规（与材料商勾结、拿隐性回扣）：
- 永久除名
- 赔偿业主损失
```

□ 服务意识好（耐心、不急躁）
□ 中立性好（不推销、不拿回扣）
□ 洞居培训合格（SOP+话术+边界）
```

#### 培训考核（2天）
```
Day 1：理论培训
- 洞居服务理念（不替业主决策）
- 各类材料知识（地砖/木地板/橱柜/卫浴）
- 价格行情数据库
- 对比表使用方法
- 话术培训（讲什么、不讲什么）
- 边界红线（什么话不能说）

Day 2：实操演练
- 模拟陪谈（导师扮演业主）
- 现场讲解材料
- 填写对比表
- 处理业主追问（"你觉得呢"）
- 考核（理论+实操）
```

### 5.2 派单规则
```
优先级：
1. 懂这个品类的接单人（地砖找懂地砖的）
2. 熟悉这个商场的接单人
3. 评分≥4.8的接单人
4. 本月服务量<15单的接单人（避免过载）
```

### 5.3 收入机制
```
方案A：平台纯服务费
- 1500积分，平台给接单人100-120元
- 不允许拿材料商回扣
- 保持绝对中立

方案B：服务费+透明回扣
- 平台给基础服务费60-80元
- 允许拿材料商回扣（如果业主成交）
- 但必须透明告知业主
- 业主同意才能拿

推荐方案A（保持中立性）
```

### 5.4 质量管控
```
抽检机制：
- 新接单人：100%抽检（前5单）
- 老接单人：20%随机抽检

抽检方式：
- 电话回访业主（服务怎么样、有没有推销）
- 查看对比报告（是否客观、有没有引导）
- 现场暗访（合伙人扮演业主，全程观察）

业主评价：
- 服务专业度（讲得清不清楚）
- 中立性（有没有推销）
- 态度（耐心、礼貌）
- 总体满意度
```
